PHẦN A — DÀNH CHO CHỦ XƯỞNG: tạo máy chủ (làm 1 LẦN duy nhất, ~5 phút)

Nếu đã làm rồi thì bỏ qua, chuyển sang Phần B.

  1. Mở file Code.gs: chuột phải file Code.gs → Open with → Notepad. Để đó.
  2. Vào script.google.com → đăng nhập Gmail của xưởng → bấm "+ Dự án mới" (New project).
  3. Dán code: bấm vào khung code → Ctrl+A → Delete (xóa code mẫu) → sang Notepad Ctrl+A, Ctrl+C → quay lại Ctrl+V.
  4. Đổi mật khẩu: tìm dòng const ADMIN_PASS = 'baobao2026'; gần đầu → sửa baobao2026 thành mật khẩu riêng (giữ 2 dấu nháy) → Ctrl+S.
  5. Deploy: bấm nút xanh Triển khai (Deploy) góc phải → Tùy chọn triển khai mới → bấm bánh răng ⚙️ → chọn Ứng dụng web (Web app) → đặt: Thực thi bằng: Tôi (Me) · Ai truy cập: Bất kỳ ai (Anyone) → Triển khai.
  6. Cấp quyền: bấm Ủy quyền truy cập → chọn Gmail → hiện cảnh báo "Google chưa xác minh" (bình thường — code của chính mình) → bấm Nâng cao (Advanced) → Đi tới ... (không an toàn) → Cho phép (Allow).
  7. Copy link: copy URL ứng dụng web (kết thúc bằng /exec) → điền vào bảng Thông tin công ty ở đầu trang này và lưu vào Zalo.
    ✅ Kiểm tra: mở link đó bằng trình duyệt — thấy chữ "May chu Bao Bao dang chay" là thành công.
  8. Kết nối máy của mình: mở baobao-app.html → bấm ⚙️ → dán link vào ô Địa chỉ máy chủ → Lưu & đăng nhập → tài khoản admin + mật khẩu vừa đặt.
  9. Tạo tài khoản nhân viên: ⚙️ Cài đặt → 👥 Tài khoản nhân viên → tạo cho mỗi người 1 tài khoản theo bảng quyền dưới đây, rồi ghi ra giấy/Zalo gửi từng người.

PHẦN B — CÀI TRÊN TỪNG MÁY TÍNH NHÂN VIÊN (~2 phút/máy)

  1. Nhận file baobao-app.html (qua Zalo/USB) → lưu ra Màn hình (Desktop) — đừng mở thẳng trong Zalo.
  2. Nháy đúp file → app mở bằng Chrome/Edge.
  3. Bấm biểu tượng ⚙️ góc trên phải → mục 🔗 Kết nối nhiều máy → dán Link máy chủ (ở bảng đầu trang) → bấm 💾 Lưu & đăng nhập.
  4. Đăng nhập bằng tài khoản + mật khẩu được cấp.
  5. ✅ Nhìn góc trên phải thấy 🟢 Đồng bộ là xong — máy này đã liên thông dữ liệu với cả công ty.
💡 Mẹo: bấm chuột phải file trên Desktop → Gửi lối tắt, hoặc trong Chrome: menu ⋮ → "Cài đặt trang dưới dạng ứng dụng" để có icon mở nhanh như phần mềm thật.

PHẦN C — CÀI TRÊN ĐIỆN THOẠI

  1. Gửi file baobao-app.html vào Zalo điện thoại → tải về → mở bằng Chrome (Android) hoặc Safari (iPhone).
  2. Làm bước 3–5 giống Phần B (dán link máy chủ → đăng nhập).
  3. Bấm menu trình duyệt → "Thêm vào màn hình chính" → có icon 🧸 ngoài màn hình, mở như app thật.

PHẦN D — DÙNG HẰNG NGÀY THEO BỘ PHẬN

🛒 Nhân viên bán hàng

  • Bấm nút xanh Bán hàng → bấm ảnh gấu (hoặc gõ tên + Enter) → nhập số lượng → gõ tên khách + ngày giao → Khách đưa tiền → THANH TOÁN. Khách đưa thiếu = tự ghi công nợ.
  • Khách trả nợ: mở hóa đơn → 💵 Thu nợ. Gửi hóa đơn cho khách: 📋 Copy hóa đơn → dán Zalo.

📦 Nhân viên kho

  • Hàng về: Hàng hóa → 📥 Nhập hàng (chọn mẫu, số lượng, giá nhập) — kho tự cộng.
  • Kiểm kê: mở sản phẩm → Kiểm kho → nhập số đếm thực tế.

💰 Kế toán

  • Sổ quỹ: tiền bán, nhập hàng, lương tự chảy vào; chi phí điện nước/quảng cáo thì bấm ＋ Phiếu chi.
  • Cuối tháng: Nhân viên → điền lương → bấm "Đã trả". Báo cáo → xem lợi nhuận, xuất CSV.

👑 Chủ xưởng

  • Tổng quan: doanh thu, chi phí, lợi nhuận, công nợ, biểu đồ — cập nhật theo thời gian thực từ mọi máy.
  • Đối tác: CRM khách hàng (khách mới/cũ, MST, email) → ⬇ Xuất DATA CRM.
