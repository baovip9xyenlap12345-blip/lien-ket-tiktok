# Nguồn: `index.html` — Trang chủ

File gốc: [`index.html`](../../../index.html) (root repo).

## Tóm tắt

Trang chủ (landing page) của ứng dụng **Lien Ket TikTok**, ngôn ngữ tiếng
Việt (`lang="vi"`), theme tối (nền đen `#010101`) với màu nhận diện lấy
theo TikTok (đỏ `#FE2C55`, cyan `#25F4EE`), font Inter.

- **Tiêu đề trang**: "Lien Ket TikTok"
- **Nhãn hiệu (badge)**: "API App"
- **Hero**: eyebrow "TikTok Developer Integration", heading "Kết nối &
  quản lý TikTok qua API", mô tả: "Ứng dụng web hỗ trợ truy xuất thông
  tin người dùng, thống kê và danh sách video từ TikTok thông qua TikTok
  API chính thức."
- **3 khối tính năng (feature cards)**:
  1. Thông tin người dùng — đọc hồ sơ công khai tài khoản TikTok đã xác thực.
  2. Thống kê tài khoản — lượt xem, follower, lượt thích tổng hợp.
  3. Danh sách video — danh sách video đã đăng kèm metadata chi tiết.
- **Phần "Quyền truy cập (Scopes)"** liệt kê 3 scope TikTok API (xem chi
  tiết ở [Khái niệm: TikTok API Scopes](../concepts/tiktok-api-scopes.md)):
  `user.info.profile`, `user.info.stats`, `video.list`.
- **Footer**: "© 2025 Lien Ket TikTok. Ứng dụng tích hợp TikTok API." +
  link tới `/privacy.html` và `/tos.html`.
